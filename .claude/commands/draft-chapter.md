## 役割

各章の `README.md` を作成し、初学者目線で品質を評価します。

## 動作モード

引数に `review` が含まれる場合は **評価モード**、それ以外は **作成モード** で動作します。

---

## 作成モード

指定された章の `README.md` を以下の手順で作成してください。

1. `docs/plans/main-plan.md` から対象章のトピック・実習内容を確認する
2. 対象章フォルダ（例: `chapter-01/`）が存在しない場合は作成する
3. CLAUDE.md に定めたセクション構成で `README.md` を作成する:
   1. 章タイトル・概要（学ぶ内容とその重要性を 2〜3 文で説明する）
   2. 学習目標（箇条書き、動詞で始める）
   3. 説明本文（概念説明、図・例、「なぜ必要か」を必ず含む）
   4. ハンズオン手順（番号付きステップ + コードブロック）
   5. 確認してみよう（3〜6問、CLAUDE.md のルール準拠）
   6. ナビゲーションバー（CLAUDE.md のルール準拠）

### 執筆の注意事項

- **対象読者**: Java 開発者で SQL 基礎あり、DBA 経験なし
- **必ず含める**: 各手順で「なぜこの操作が必要か」の説明
- **コマンドブロック**: 実際に Codespaces で動作するコマンドのみ記載
- **日本語**: すべて日本語で記述する

## 評価モード

指定された章の既存 `README.md` を以下の観点でレビューしてください。

### 評価観点

| 観点 | 確認内容 |
|---|---|
| 初学者理解度 | DBA 未経験者が読んで「なぜ必要か」を理解できるか |
| 操作手順の正確さ | コマンドが Oracle Linux 8 + Oracle DB 21c XE で動作するか |
| 確認問題の品質 | 理解度を適切に問えているか（Yes/No で答えられる問いは NG） |
| セクション構成 | CLAUDE.md に定めた必須セクションがすべて揃っているか |
| ナビゲーションバー | パスとリンクが正しいか |

### 評価結果の形式

```markdown
## レビュー結果: 第NN章

### 総合評価: [良好 / 要改善 / 要作り直し]

### 良い点
- 〜

### 改善点
| 箇所 | 問題 | 改善案 |
|---|---|---|
| セクション名 | 問題の内容 | 具体的な改善案 |
```
